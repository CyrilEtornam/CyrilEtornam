### Systems with a real-world job to do

- [**Nkwa**](https://github.com/CyrilEtornam/project-nkwa) is a multilingual emergency copilot for Ghana's 112 line. It takes a voice message, works out what is happening, finds a recognisable location, and gives first-aid guidance in the caller's language. Built across FastAPI, React, AWS Bedrock, and a mobile client.
- [**Emergency Response Platform**](https://github.com/CyrilEtornam/emergency-response-platform) is a backend-heavy response system split into services for things like auth, dispatch, and analytics, with Spring Boot, RabbitMQ, Redis, Docker, and an API gateway in the mix.
- [**Tellme**](https://github.com/CyrilEtornam/tellme) is a Linux talking clock and calendar helper. It runs at login, speaks reminders with an offline neural voice, and is built to keep working even when the internet does not.
- [**TaskFlow**](https://github.com/CyrilEtornam/Task-Flow) is a responsive Django task manager with accounts, priorities, due dates, and views for what is due now, this week, or already overdue.

### Smaller tools, built for the little annoyances

- [**qrscan**](https://github.com/CyrilEtornam/qrscan) lets me select a part of my Linux screen, decode a QR code, copy the result, and get on with my day without reaching for my phone.
- [**textscan**](https://github.com/CyrilEtornam/textscan) is a Linux OCR helper for pulling text from images without turning a simple task into a whole process.
